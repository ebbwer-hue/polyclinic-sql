# Polyclinic SQL

**Автор проекта: Кушалиев Амир** · [Telegram: @foidslayer1038](https://t.me/foidslayer1038)

Учебная реляционная база данных поликлиники для Microsoft SQL Server: врачи, специальности, пациенты, диагнозы и приёмы.

**Стек:** T-SQL · Microsoft SQL Server.

## Содержание

- Создание базы данных и таблиц.
- Первичные и внешние ключи, ограничения уникальности.
- Демонстрационные записи.
- Примеры INNER JOIN, LEFT JOIN и RIGHT JOIN.
- Подробный разбор запросов в `poyasneniya.md`.

## Запуск

Откройте `polyclinic.sql` в SQL Server Management Studio и выполните на учебном экземпляре SQL Server с правом создания баз. Скрипт создаёт базу `Polyclinic_PZ31`; для повторного запуска используйте чистый учебный экземпляр или адаптируйте имя базы.
